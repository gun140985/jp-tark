# 한일 통역

일본인과 마주 보고 대화할 때 쓰는 안드로이드 통역 앱 (개인용, 무료).

## 기능
- **상대 말 듣기**: 일본어를 듣고 일본어 원문, 한글 발음, 한국어 번역을 보여주고 한국어로 읽어줌
- **내 말 하기**: 한국어를 듣고 일본어와 큰 한글 발음을 보여주고, 일본어로 읽어줌
- **자주 쓰는 말**: 기본 8문장 + 내 문장 추가·삭제
- **마이크·스피커 설정**: 마이크(본체/블루투스), 소리 출력(이어폰/스피커/자동), 읽는 속도, 자동 읽기
- 무료 번역(구글 ML Kit, 처음 한 번 내려받으면 인터넷 없이 번역)

## 설치 (휴대폰만으로)
1. 이 저장소의 **Releases → 한일 통역 최신 버전 → jp-talk.apk** 를 눌러 내려받기
2. 내려받은 파일 열기 → "출처를 알 수 없는 앱" 허용 → 설치
3. Play 프로텍트 경고가 뜨면 "무시하고 설치" (내가 만든 앱이라 정상)
4. 처음 실행 때 마이크 권한 허용, 와이파이에서 번역 데이터 내려받기

코드를 고치면 자동으로 새 APK가 만들어지고, 같은 방법으로 덮어 설치하면 됩니다.
